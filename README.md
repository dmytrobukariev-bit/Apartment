# Бот поиска жилья в Апельдорне

Каждые ~10 минут проверяет сайты аренды и присылает в Telegram студии и
квартиры в Апельдорне. Работает бесплатно на серверах GitHub, компьютер
можно выключать.

## Как пользоваться в Telegram
Объявления приходят **по одному**, сначала ⭐ (подходят под твои критерии):
- **👍 Оставить**: объявление остаётся в чате с пометкой 💚, приходит следующее
- **👎 Не то**: объявление удаляется, приходит следующее
- У сохранённых есть кнопка **🗑 Убрать из сохранённых**

Команды: `/saved` (список сохранённых), `/queue` (сколько осталось),
`/next` (если следующее не пришло).

Бот работает непрерывно: каждый запуск на GitHub длится ~5,5 часа, потом он
сам запускает следующий. Если цепочка вдруг оборвётся, раз в час её
перезапускает расписание.

| Источник | Статус |
|---|---|
| Nederwoon (агентство в Апельдорне) | ✅ работает, много студий |
| Marktplaats | ✅ работает (только разделы «сдаётся», без гаражей и «ищу жильё») |
| Kamernet | ✅ работает, показывает, разрешена ли регистрация |
| Kamer.nl | ✅ работает |
| 123wonen | ✅ работает |
| Pararius, Huurwoningen | ⚠️ часто блокируют ботов, бот пробует их и пропускает, если закрыто |
| Funda, Huurstunt, HousingAnywhere, Woonkeus, Facebook | ❌ бот туда не достаёт |

Где зарегистрироваться самому, чтобы покрыть остальное, написано в файле
**«Где зарегистрироваться.md»**.

Одно и то же жильё иногда висит на двух сайтах (например, Nederwoon и
Marktplaats), тогда оно придёт дважды.

Фильтр задаётся в `config.json`: город, цена, макс. число комнат (в NL «2 kamers» —
это квартира с одной спальней), типы жилья, дата, к которой нужно жильё.
Объявления, где прямо написано «без регистрации», бот не присылает.

Блок `extra` задаёт расширенный поиск (сейчас до €1000, включая комнаты и дома).
Такие объявления приходят с пометкой «ℹ️ Дополнительный вариант», а подходящие
под основные критерии с пометкой «⭐».

## Настройка (≈15 минут)

### 1. Создай Telegram-бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя.
2. Он пришлёт **токен** вида `123456:ABC...`. Никому его не показывай.
3. Найди своего бота и напиши ему `/start`.
4. Узнай свой chat id:
   ```
   pip install requests
   python get_chat_id.py ТВОЙ_ТОКЕН
   ```

### 2. Залей проект на GitHub
1. Зарегистрируйся на github.com.
2. Создай **публичный** репозиторий (New repository), например `huizen-bot`.
   Публичный, потому что для публичных репозиториев запуски бесплатные без
   лимита. Токен туда не попадёт, он хранится в секретах.
3. Загрузи все файлы из этой папки (кнопка «uploading an existing file»),
   включая папку `.github`.

### 3. Добавь секреты
Settings → Secrets and variables → Actions → **New repository secret**:
- `TELEGRAM_TOKEN`: токен от BotFather
- `TELEGRAM_CHAT_ID`: число из шага 1

### 4. Запусти
Вкладка **Actions** → «Проверка жилья» → **Run workflow**. Через минуту в
Telegram придёт всё, что подходит сейчас, и сообщение «Бот запущен». Дальше
бот будет присылать только новое.

## Обязательно включи уведомления на сайтах
Бот покрывает не всё. Подробная инструкция, где и как подписаться, лежит в файле
**«Где зарегистрироваться.md»**.

## Как не нарваться на мошенников
- Не плати ничего до просмотра жилья (вживую или по видеосвязи с хозяином в квартире).
- «Я за границей, отправлю ключи после оплаты» — это всегда обман.
- Цена сильно ниже рынка (студия за €400) — повод насторожиться.
- Проверь, что регистрация (inschrijving) по адресу разрешена, и что это указано в договоре.
- Депозит обычно 1–2 месячные аренды, не больше.

## Полезное
- Через 60 дней без коммитов GitHub отключает расписание, но бот сам делает
  коммит при каждом новом объявлении, так что это не страшно.
- Чтобы остановить бота: Actions → «Проверка жилья» → «…» → Disable workflow.
- Локальная проверка без отправки: `python huizen_bot.py --dry-run`.
